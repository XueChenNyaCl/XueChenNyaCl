# Hello, I'm NyaCl

Welcome to my personal blog!

## About This Site

This is a floating pseudo-3D interface blog built with Vue 3 + TypeScript. All sections are displayed as draggable windows floating on the main interface, creating a unique visual experience.

## Tech Stack

- **Frontend**: Vue 3 + TypeScript
- **Build Tool**: Vite
- **State Management**: Pinia
- **Styling**: CSS3 + Liquid Glass Effects
- **Deployment**: GitHub Pages
