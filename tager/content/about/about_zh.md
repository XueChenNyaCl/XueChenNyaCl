# 你好，我是 NyaCl

欢迎来到我的个人博客！

## 关于本站

本站运用到的样式主要以css为主，js的动画效果比较少，主要是为了保持页面的响应性和性能。运用了大量的ts来处理一些逻辑和动画效果。如果明显感觉动画卡顿且响应较慢，请在设置里调整动画效果。

本站的图片和元素大多来自于画师甘城なつき/Nachoneko([@amsrntk3](https://x.com/amsrntk3))以及其他同人画师作品,部分作品进行了修改，如有侵权请联系我。

## 技术栈

- **前端框架**: Vue 3 + TypeScript
- **构建工具**: Vite
- **部署**: GitHub Pages
