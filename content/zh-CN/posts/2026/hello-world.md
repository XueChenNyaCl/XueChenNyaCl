# 欢迎来到我的博客

这是我的第一篇博客文章！很高兴能够在这里分享我的想法和经验。

## 关于这个博客

这个博客采用了**漂浮式伪3D界面**设计，使用 Vue 3 + TypeScript 技术栈开发。所有的内容板块都以可拖动的窗口形式漂浮在主界面上。组件系统方便添加更多的功能模块。

<!-- more -->

## 主要功能

### 文章管理

- 支持 Markdown 格式编写文章
- 自动提取文章摘要
- 标签分类系统

### 界面特色

- 伪玻璃风格的 UI 设计
- 可拖动、可调整大小的窗口
- 响应式布局适配
- 流畅的动画效果

## 技术栈

const techStack = {
